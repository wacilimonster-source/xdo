# X 下载助手 · UI/UX 整体优化方案

- 版本基准:v0.2.11(versionCode 22)
- 配套原型:`design/ui-prototype.html`(浏览器打开,左侧导航切换全部页面/弹窗/状态,手机框内可直接交互,舞台右上角可开「显示优化标注」)
- 方向:**深色单主题(X Lights out 风格)** · 保持 4 页信息架构 · 适度重构

---

## 0. 优化原则

1. **高频操作一步直达**:暂停/取消/继续/重试等下载高频操作,从「三点菜单二级入口」提升为卡片内联按钮。
2. **破坏性操作分级**:可恢复的删除(单条记录)→ 滑动即删 + Snackbar 撤销;不可恢复的删除(清空全部、删除含媒体文件的记录)→ 明确后果的确认弹窗。统一「先轻后重」策略,去掉目前"单条删除零确认、重要确认又文案模糊"的混乱状态。
3. **状态可视化**:下载速度/剩余时间、文件大小预估、格式(HLS/MP4)、时长、清晰度徽章全部上卡片,用户不再"盲下"。
4. **反馈闭环**:每个动作都有可感知结果(复制→Snackbar、删除→撤销、已下载过→可跳转查看),消灭"点了没反应"的交互(设置页版本行、播放页复制链接)。

## 1. 设计系统

### 1.1 色板(对齐 X「Lights out」)

| Token | 值 | 用途 |
|---|---|---|
| bg | `#000000` | 页面背景 |
| surface | `#16181C` | 卡片/输入框/弹窗底 |
| surface-2 | `#202327` | Snackbar/悬浮菜单/输入框 hover |
| border | `#2F3336` | 描边/分隔线 |
| text | `#E7E9EA` | 主文本 |
| text-2 | `#71767B` | 次文本/占位 |
| blue | `#1D9BF0` | 主操作/选中/进度/链接 |
| green | `#00BA7C` | 成功/已完成 |
| red | `#F4212E` | 错误/破坏性操作 |
| yellow | `#FFD400` | 暂停/警告 |

落地:删除 `Theme.kt` 的 `lightColorScheme` 分支,固定深色 `darkColorScheme`,移除 `isSystemInDarkTheme` 依赖。

### 1.2 形状与字体

- 圆角:卡片/弹窗 16dp,缩略图/输入框 12dp,按钮全圆角 pill。
- 字体:默认 system;标题 18–20sp bold,正文 15sp,辅助 13sp,徽章 11sp。
- 按钮:主按钮 = 蓝底白字 pill;次按钮 = 透明底 + `#2F3336` 描边 pill;破坏性 = 红底白字或红字文本;行内小按钮 = 小号 pill(28dp 高)。

## 2. 信息架构(不变)

```
AppRoot
├─ 首页(记录列表 + 搜索/粘贴解析入口)
├─ 解析页(清晰度选择,含解析中/失败态)
├─ 播放页(全屏播放)
└─ 设置页
+ 全局:更新弹窗(AppRoot 持有)/ Snackbar / 通知
```

页面数量与导航关系全部保持,优化集中在页内结构、状态表达与弹窗规范。

## 3. 逐页优化明细

编号与原型中的「显示优化标注」圆点一致。

### 3.1 首页 Home

**现状问题**:搜索框身兼两职无状态区分;暂停/取消藏在三点菜单(两步);滑动删除无确认不可撤销;失败无内联重试;无筛选;通知权限裸弹;菜单「复制链接」用了 List 图标。

| # | 优化点 | 说明 |
|---|---|---|
| H-01 | 搜索/解析双模式输入框 | 同一个输入框,检测到 X 链接时边框变蓝并出现「解析」pill 按钮;普通文本走搜索并实时过滤;空文本显示占位「搜索记录,或粘贴 X 链接」。普通文本态加清除按钮。 |
| H-02 | 状态筛选 chips | `全部 / 进行中 / 已完成 / 失败`(带计数)。进行中 = PARSING/READY/DOWNLOADING/PAUSED;失败 = FAILED。 |
| H-03 | 卡片内联下载控制 | 下载中:进度条 + `68% · 2.4MB/s · 剩余8s` + 内联 ⏸/✕;已暂停:`已暂停 · 42%` + 内联「继续」;失败:错误文案 + 内联「重试」;已解析:「待选择清晰度」+ 内联「继续」。不再进菜单。 |
| H-04 | 卡片信息增强 | 缩略图放大为 16:9(112×63),叠加时长徽章与播放图标;标题下行显示 `作者 @handle · 时间`;DONE 行显示 `720p 徽章 · 14.3MB`(数据已有 `chosenLabel/fileSize`)。 |
| H-05 | 滑动删除 + 撤销 | 左滑即删,底部 Snackbar「已删除「xxx」· 撤销(5s)」。去掉逐条确认。**落地注意**:`deleteRecord` 目前同步删媒体文件,需改为延迟执行(先删记录行、挂起 5s 后清文件)或先做标记。 |
| H-06 | 三点菜单重组 | 图标语义修正(复制链接=Copy 图标);按状态给出菜单项,「删除」红色文字置底;菜单内删除走与滑动一致的撤销流程。 |
| H-07 | 剪贴板 banner 优化 | 文案精简为「检测到剪贴板中的 X 链接」+ 内联「解析」pill;解析后自动消失(现状保留)。 |
| H-08 | 空状态三步引导 | 首次使用:插画 + 「在 X 打开视频推文 → 点分享选择本应用 → 选清晰度下载」三步说明;搜索无结果:「没有匹配「xx」的记录」+「清除搜索」按钮(保持 B33 区分)。 |
| H-09 | Snackbar 带动作 | 「该视频已下载过」+ [查看](跳播放);「未识别到 X 链接」;「链接已复制」等统一深灰 pill + 蓝色动作。 |
| H-10 | 通知权限前置说明 | 首次启动先弹应用内说明(为什么需要/不开也能用),确认后再拉起系统弹窗,替代裸系统弹窗。 |

### 3.2 解析页 Resolve

| # | 优化点 | 说明 |
|---|---|---|
| R-01 | 清晰度卡片增强 | 每行:`1080p` + 格式徽章 `HLS`/`MP4` + 匹配默认设置时显示「默认」徽章 + 右侧预估大小 `≈ 53.9MB`(`bitrate × durationMs` 可算)+ 码率小字。 |

## 4. 弹窗与反馈规范

- **中央 AlertDialog**:需要决策的中断(移动网络确认/文件丢失/删除确认/清空确认/更新)。按钮:右侧主操作(filled;破坏性用红底),左侧次操作(text)。
- **Bottom Sheet**:选择型(清晰度)与次级操作菜单(播放页 ⋯)。从底部滑入,下拉或点击遮罩关闭。
- **Snackbar**:操作反馈与可撤销操作,深灰 pill,动作蓝色加粗,4s 自动消失,最多同时 1 条。
- **移动网络确认**两处(首页/解析页)共用同一文案与按钮序,解析页文案附上预估大小。

弹窗清单(9 个,较现状 +1):

| 弹窗 | 页面 | 主操作 | 变化 |
|---|---|---|---|
| 通知权限前置说明 | 首页(首启) | 去开启 | 新增 |
| 文件已丢失 | 首页 | 重新下载(filled)/ 删除记录(红文本) | 文案明确 |
| 移动网络确认 | 首页/解析页 | 继续下载(filled) | 文案统一 |
| 更新弹窗(3 态) | 全局 | 立即更新/取消下载/重试 | 按钮真实可点、失败可重试 |
| 清晰度选择 | 设置(Bottom Sheet) | 完成 | 换形态+说明 |
| 清空历史 | 设置 | 清空(红 filled) | 带数量+红按钮 |
| 播放页删除 | 播放页 | 删除(红 filled) | 文案明确后果 |
| 记录 ⋯ 菜单 | 首页 | — | 重组+图标修正 |
| 播放页 ⋯ 菜单 | 播放页(Bottom Sheet) | — | 新形态 |

## 5. 通知栏(关联 BUG_REPORT B28/B29 残留)

| 态 | 标题 | 正文 | 动作 |
|---|---|---|---|
| 下载中 | 正在下载「标题」 | `68% · 12.3/14.3MB` | 暂停 / 取消 |
| 完成 | 下载完成「标题」 | `720p · 14.3MB` | 播放 |
| 失败 | 下载失败「标题」 | 具体原因(区分网络/磁盘/解析) | 重试 |

并发下载按 recordId 分通知 id(修复 B28 两个任务共用通知),服务保活通知与任务通知分离。

## 7. 原型使用说明

1. 双击打开 `design/ui-prototype.html`(Chrome/Edge,窗口宽度 ≥ 1100 体验最佳,窄屏自动单列)。
2. 左侧三组导航:**页面** / **弹窗与浮层** / **系统界面**;弹窗条目 = 对应页面叠加弹窗后的效果。
3. 手机框内可交互:筛选 chips、搜索输入(粘贴含 `x.com/i/status/` 的文本会出现「解析」按钮)、卡片 ⋯ 菜单、左滑删除 + 撤销、播放页点击显隐控制条、清晰度选择、设置 sheet 等。
4. 舞台右上角「显示优化标注」开关:在关键改动点显示编号圆点(对应本文档 H-/R-/P-/S- 编号),悬停查看说明。
